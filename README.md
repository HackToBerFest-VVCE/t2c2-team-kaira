Vibe Guard 🛡️

AI-Assisted Security Gatekeeper for Web Applications

Vibe Guard is a web application security platform designed to help developers identify vulnerabilities before deployment. It aims to make application security simpler and more accessible by combining automated security checks, understandable risk explanations, remediation guidance, and fix verification.

🎯 Project Objectives

- Identify security vulnerabilities and insecure configurations before deployment.
- Detect exposed secrets and vulnerable software dependencies.
- Explain security findings and recommend practical fixes.
- Verify whether identified issues have been resolved.
- Integrate security checks into the development and deployment workflow.

✨ Key Features

- Security Dashboard: Present security findings, severity levels, and an overall security overview.
- Automated Security Scanning: Identify code vulnerabilities, exposed secrets, dependency issues, and website security weaknesses.
- Security Advisor: Explain risks and suggest appropriate remediation steps.
- Fix & Verify: Recheck applications after fixes to help confirm that issues have been addressed.
- Deployment Gate: Prevent deployment when mandatory security checks fail.

🛠️ Technology Stack

- Frontend: Next.js, React, TypeScript
- Styling: Tailwind CSS
- Backend: Next.js API routes with Node.js
- Code Security Analysis: Semgrep
- Secret Detection: Gitleaks
- Dependency Auditing: "npm audit", "pip-audit"
- CI/CD: GitHub Actions
- Development Tools: Visual Studio Code, GitHub Copilot

💡 Our Innovation

Don't just detect vulnerabilities. Help developers fix them and verify the fixes before deployment.

Vibe Guard aims to bridge the gap between discovering security issues and ensuring that applications are ready for safer deployment.
